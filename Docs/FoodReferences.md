# v0.5 料理モデルの写真参照

2026-11-04に公開写真を確認。写真は形状・盛り付け・色・質感の参考のみとし、ゲームのテクスチャや配布物には使用していない。

- [S&B「基本のカレーライス」](https://www.sbfoods.co.jp/recipe/detail/01915.html)：白いご飯とルーを左右に盛り分ける構成、浅いルーの広がり、つやのある具材を参考にした。ゲームの食材ルールに合わせた仮想の肉・野菜の盛り付けであり、写真のレシピを再現するものではない。
- [キッコーマン「まろやかマーボー豆腐」](https://www.kikkoman.co.jp/homecook/search/recipe/00005828/)：淡い色の角切り豆腐、表面を覆う茶赤色の餡、細かなひき肉、刻みねぎを参考にした。

## モデルと盛り付け

| 料理 | v0.4の三角形数 | v0.5の三角形数 | 変更 |
|---|---:|---:|---|
| カレー | 460 | 18,016 | ご飯の山＋114粒の米＋浅いルー＋角の丸い肉・野菜＋玉ねぎ片 |
| 麻婆豆腐 | 184 | 22,060 | 赤い油と餡＋21個の角切り豆腐＋125個のひき肉片＋刻みねぎ |
| 専用の磁器皿 | 平面128 | 1,344 | 底と立ち上がり、縁の厚みを持つ皿 |

この2料理は大皿1枚につき料理全体のメッシュを1つ描く。旧方式のように小さな料理模型を何十個も積まない。
数量が増えると、皿の大きさと料理の盛り上がりが増える。ゲーム上の正確な数量はECSのStockで保持する。
米・豆腐・餡のつやを頂点カラーの補助値で調整し、ソースに強めのハイライトを加える。

実装：`Rendering/FeastMeals.cs`、`Rendering/FeastMeshes.cs`、`Rendering/FeastView.cs`、`Resources/FeastLit.shader`。
