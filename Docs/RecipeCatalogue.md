# レシピ一覧：400種類

材料は1人前の必要数。「／」は代用候補。Enterで可能な最大数を一括調理し、得点×人前を獲得する。
完成料理は誰が作ったものでも次の料理に使える。前半200種はレシピ順・材料・得点・発見セーブを維持。後半200種は実在する料理名に差し替えた。食材は従来と同じ35種類。
調味料や麺の種類などを共通化したゲーム用の簡略レシピであり、実際の料理手順ではない。
