### 演出の実行検査を再現する

ビルド後、プロジェクトのルートで実行する。発見セーブを読み書きせず、約2分15秒で終了する。

```sh
"Builds/熱烈電卓町中華.app/Contents/MacOS/熱烈電卓町中華" \
  -batchmode -nographics -feast-effects-test -feast-output "$PWD/Docs" \
  -logFile /tmp/spinning-feast-effects.log
```

描画なしの場合はECSと演出の寿命・イベントを検査し、画像品質やGPU速度は判定しない。
通常プレイの完了時には、ローカルの `Application.persistentDataPath/last-match-profile.json` に直近1試合の性能記録だけを書き出す。入力文字を記録せず、外部へ送信しない。
